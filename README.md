# AntoPistolero-Call

Distribuzione binaria dell'edizione Windows con tema esclusivo Napoli / BMW M.

**[Scarica l'installer e Call Bridge Android](https://github.com/baciulavoro23-png/AntoPistolero-Call-Releases/releases/latest)**.

L'edizione usa installazione, dati, collegamenti e profilo Chrome CRM propri. Alla prima apertura copia gli account e l'associazione Call Bridge dell'installazione EderaAutoCall presente sullo stesso PC, senza modificare l'originale. Per Chrome CRM occorre effettuare l'accesso nel nuovo profilo.

La build 2.2.0 usa gli installer dedicati per gli aggiornamenti; il suo aggiornamento automatico e disabilitato. Non installa pacchetti dal canale EderaAutoCall.

La versione normale resta nel [repository EderaAutoCall-Releases](https://github.com/baciulavoro23-png/EderaAutoCall-Releases/releases/latest). Le due distribuzioni restano separate.

Su Android installare Call Bridge 1.1.4 sopra la 1.1.3 senza disinstallare, per conservare l'associazione. Su iPhone la pagina Bridge aggiunta alla Home e gia aggiornata.

Questo repository contiene solo documentazione di distribuzione e pacchetti compilati. Non contiene sorgenti del progetto, account, database o chiavi private.
